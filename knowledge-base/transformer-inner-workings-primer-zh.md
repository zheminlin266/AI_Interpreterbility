## 论文回答什么问题？

这是一份以**生成式、仅解码器 Transformer** 为重点的技术综述。作者先介绍模型怎样计算下一个 token 的分数，再把解释方法分成两组：**行为定位**问哪些输入或内部组件影响预测，**信息解码**问哪些信息能从内部表征中读出。最后，作者用注意力头、前馈网络、残差流和多组件回路的案例说明这些方法能发现什么。[引言，§1](https://arxiv.org/html/2405.00208v3#S1)

## 先看懂模型的计算路径

每个 token 位置都有一条逐层更新的**残差流**。在论文介绍的结构中，注意力头用查询和键（QK）决定从哪些位置读取、各占多大权重，再通过值和输出投影（OV）决定向残差流写入什么；前馈网络（FFN，也常称 MLP）对每个位置单独计算并写回更新。末端的输出头把表征映射到词表分数（logits）。残差流的加法结构便于拆分组件的写入贡献，但一次前向传播中的分数拆分不能替代干预：修改早期组件后，下游组件的计算也可能改变。[模型组件与分解，§2](https://arxiv.org/html/2405.00208v3#S2)

## 两条分析路线，三种证据

| 方法 | 能回答的问题 | 不能单凭它得出的结论 |
| --- | --- | --- |
| [输入归因，§3.1](https://arxiv.org/html/2405.00208v3#S3.SS1) | 按所选归因规则，哪些输入 token 对指定预测重要？ | 重要 token 不揭示模型内部如何处理它；注意力权重本身也不包含写入内容和下游效应。 |
| [直接 logit 归因，§3.2.1](https://arxiv.org/html/2405.00208v3#S3.SS2.SSS1) | 在这次运行中，某组件的写入直接贡献了多少目标 logit？ | 这不等于移除组件后的变化，也不计它经其他组件产生的间接影响。 |
| [激活替换，§3.2.2](https://arxiv.org/html/2405.00208v3#S3.SS2.SSS2) | 将指定激活替换为对照运行中的值后，目标指标怎样变化？ | 效应取决于替换来源、位置和指标，不能直接推广到其他输入、任务或模型。 |
| [回路分析，§3.2.3](https://arxiv.org/html/2405.00208v3#S3.SS2.SSS3) | 哪些组件通过哪些连接协作实现行为？边或路径替换可以检验特定交互。 | 找到一条有效路径不意味着它是唯一的，也不意味着整项行为都已解释。 |
| [探针，§4.1](https://arxiv.org/html/2405.00208v3#S4.SS1) | 用监督读出器能否从某处激活预测带标签的属性？ | 高分不证明原模型使用了这个属性；还要考虑读出器自身学会任务的可能。 |
| [稀疏自编码器（SAE），§4.2](https://arxiv.org/html/2405.00208v3#S4.SS2) | 哪些稀疏特征可以近似重建激活，并作为解释候选？ | 字典不是唯一的，也不保证每个特征都对应一个可命名概念。 |
| [Logit lens 与 tuned lens，§4.3](https://arxiv.org/html/2405.00208v3#S4.SS3) | 把中间状态映射到词表，会读出哪些候选 token？Tuned lens 先用学习到的映射变换表征。 | 读出的分布不等于原模型经后续层计算得到的预测，也不证明某个 token 信号有因果作用。 |

笔记的判断顺序：**能读出信息 → 干预能改变行为 → 能解释组件如何协作**。每一步都需要相应的额外证据。

## 两个机制案例

- **归纳头（induction head）。** 在 `A B … A` 的模式中，一种经典的双头机制里，前一 token 头先把 `A` 的信息传到较早的 `B` 位置；归纳头便可从当前 `A` 找到那个位置，并提高预测 `B` 的分数。这个案例展示了 QK 的位置匹配和 OV 的复制作用；它只解释特定的续写模式，不能概括所有上下文学习。[归纳与复制，§5.1.2](https://arxiv.org/html/2405.00208v3#S5.SS1.SSS2)
- **间接宾语识别（IOI）。** 综述引用 Wang 等人在 GPT‑2 Small 上的研究：句子先介绍 Mary 和 John，然后让 John 给某人递东西，目标是预测 Mary。候选回路中，一组头传递 John 重复出现的信号，另一组头利用该信号抑制对 John 的选择，名字复制头再推动对 Mary 的预测。这个结果限于所研究的模型与提示分布。[多组件行为，§5.4，图 15](https://arxiv.org/html/2405.00208v3#S5.SS4)

## 怎么读、怎么用？

- **想上手实验：** 先读 §2 的结构图，再读 §3.2.2 的激活替换，最后对照 §5.4 的 IOI 案例。可以用成对提示和留出样本检验同一行为，记录替换位置、对照来源与目标 token 的 logit 差，再检查结论是否随对照改动而改变。这是本站建议的练习，未在本仓库运行。[工具概览，§6](https://arxiv.org/html/2405.00208v3#S6)
- **想看证据边界：** 先读 §4 区分读出和干预，再读 §7。作者提出的关键挑战之一，是让在受控小任务上得到的发现能真正帮助调试模型、改善可靠性；综述没有证明这种迁移已经实现。[结论与未来方向，§7](https://arxiv.org/html/2405.00208v3#S7)

想对照传统机器学习方法或追踪后续方向，可继续读本站的[可解释性方法综述](/articles/ai-interpretability-methods/)。
