# 引言解读：为什么要逆向工程 Transformer？

> 根据 [ChatGPT 分享对话](https://chatgpt.com/share/6b08f3b6-104c-83ea-9730-47c7bf64460d) 整理。阅读范围是[英文原文](https://transformer-circuits.pub/2021/framework/index.html)开头至「结果摘要」之前。已核对原文，未复现实验；下面的预测用于举例。

## 答对以后，还能追问什么？

假设给语言模型输入 `The capital of France is`，它给 `Paris` 打了最高分。看到输出，我们知道它预测了什么。论文关心的是，这个分数在模型内部是怎样算出来的：哪些组件读到了和法国有关的信息？信息传到了哪里？哪些计算把 `Paris` 的分数推高了？

**机制可解释性**试图用可以检查的内部计算回答这些问题。文章把它比作**逆向工程**：一般的软件可以回去读程序员写的源码，而训练得到的语言模型只有现成的计算结构和一大组学出的参数。研究者需要从这些参数以及模型运行时的数值，推断模型用的是什么办法。

![训练从数据出发得到模型权重；逆向工程从权重出发分析内部计算、理解算法](/guide-images/training-and-reverse-engineering.svg)
图 1. 训练和逆向工程从哪里出发？ · [据分享对话重绘][figure-source]

- **权重（weights）**是训练学出的参数。处理一条输入时，通常保持不变。
- **激活值（activations）**是模型处理这条输入时产生的中间数值。换一条输入，它们就可能不同。
- **回路（circuit）**是一组能够共同实现某项行为的计算和连接。只凭一次正确预测，还不能定位这条回路；还要检查内部计算是否支持这个解释。

## 为什么从零层、单层、双层开始？

论文先做减法：主要研究最多两层、去掉前馈网络（MLP）的纯注意力模型。可以把结构先记成 `输入 token → 嵌入 → 0～2 层注意力 → 反嵌入 → 候选分数`。**嵌入**把 token 转成一组数；**反嵌入**把内部数值变成各个候选 token 的分数。

![三种模型都有嵌入 E 和反嵌入 U，中间依次放零层、一层或两层注意力](/guide-images/model-depth.svg)
图 2. 三种简化模型的结构对照。E 表示嵌入，U 表示反嵌入。 · [据分享对话重绘][figure-source]

- **零层**没有跨位置读取，只能从当前 token 出发预测下一项。
- **单层**的注意力头可以读取前文，将有用的信息带到当前位置。
- **双层**的后一层可以利用前一层写下的信息。这样就有机会把「找到之前的匹配」和「取出匹配后面的内容」接成一个算法。

例如，在 `A B … A` 里，先前的 `A` 后面是 `B`，现在又看到 `A`，模型可能据此提高 `B` 的分数。论文把能实现这种模式的一类注意力头叫作**归纳头**。这是对特定简化模型机制的解释，不能直接用来解释现代语言模型的所有预测。见原文[模型简化](https://transformer-circuits.pub/2021/framework/index.html#model-simplifications)与[归纳头工作原理](https://transformer-circuits.pub/2021/framework/index.html#how-induction-heads-work)。

![序列重复出现 A B C D。末尾的 C 回看之前的一次 C，利用其后的 D 预测下一项](/guide-images/induction-pattern.svg)
图 3. 把例子里的 A、B 换成 C、D，就能在重复序列中看到同一个归纳模式。 · [据分享对话重绘][figure-source]

## 补充：人工神经网络和大脑有什么不同？

这是分享对话中的背景问答，论文引言没有展开这个话题。可以把问题拆成**用什么实现**和**怎样传递信息**两层：

- **数字计算机**用晶体管电路实现二进制运算。二进制也能表示小数，所以人工神经网络的输入、中间数值和权重可以是小数。以接收两个输入的人工神经元为例：

  ![输入 x₁ 和 x₂ 分别乘以权重 w₁ 和 w₂，再与偏置 b 相加，经激活函数 f 得到输出 y](/guide-images/artificial-neuron.svg)
  图 4. 双输入人工神经元的计算过程，对应下方公式。 · [据分享对话重绘][figure-source]

  ```mathml
  <mtable>
    <mtr><mtd><mi>z</mi><mo>=</mo><msub><mi>w</mi><mn>1</mn></msub><msub><mi>x</mi><mn>1</mn></msub><mo>+</mo><msub><mi>w</mi><mn>2</mn></msub><msub><mi>x</mi><mn>2</mn></msub><mo>+</mo><mi>b</mi></mtd></mtr>
    <mtr><mtd><mi>y</mi><mo>=</mo><mi>f</mi><mo>(</mo><mi>z</mi><mo>)</mo></mtd></mtr>
  </mtable>
  ```

  先用权重 w 调整各个输入 x，求和并加上偏置 b，得到 z；再把 z 交给激活函数 f，得到输出 y。

- **大脑**的神经元通过离子流动改变膜电位，并经由突触传递信号。可以把一小段时间内「有没有发出脉冲」记成 0 或 1，但膜电位会连续变化，脉冲的时机和频率也能携带信息。

  ![膜电位从静息水平升至示意阈值后短暂冲高，随后下降并回到静息水平](/guide-images/membrane-potential.svg)
  图 5. 动作电位的示意波形，数值会随神经元类型和条件变化。 · [据分享对话重绘][figure-source]

两者都可以通过许多相连的单元处理信息。这个类比有助于提出问题，却不能证明两者用了相同的算法。对机制可解释性来说，人工网络有一个实验便利：在能访问模型内部的情况下，可以记录中间值，对某个组件做有对照的改动，再观察预测如何变化。

## 接下来怎么读？

先到「结果摘要」比较三种小模型；读到残差流和注意力时，再补向量、矩阵和点积；读到单层与双层的推导时，重点追踪「信息从哪里来、被写到哪里、怎样影响预测」。不需要先学完整套高等数学。
