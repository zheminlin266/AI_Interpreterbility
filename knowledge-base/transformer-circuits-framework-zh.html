Transformer[1] 语言模型是一项新兴技术，在现实世界中的应用越来越广泛，例如在 GPT-3 [2]、LaMDA [3]、Codex [4]、Meena 等系统中[5]、Gopher [6] 及类似型号。然而，随着这些模型的扩展，它们的开放性和高容量为意外且有时有害的行为带来了越来越大的范围。即使在训练大型模型数年后，创建者和用户仍然会经常发现他们以前没有意识到的模型功能（包括有问题的行为）。

解决这些问题的一种途径是 机制可解释性 ，尝试对 Transformer 执行的详细计算进行逆向工程，类似于程序员尝试将复杂的二进制文件逆向工程为人类可读的源代码。如果这是可能的，它可能会提供一种更系统的方法来解释当前的安全问题，识别新的安全问题，甚至可能预测尚未构建的强大未来模型的安全问题。之前的项目 Distill Circuits thread [7] 曾尝试对视觉模型进行逆向工程，但到目前为止还没有类似的Transformer或语言模型项目。

在本文中，我们尝试采取初步的、非常初步的步骤来对Transformer进行逆向工程。鉴于现代语言模型令人难以置信的复杂性和规模，我们发现从最简单的模型开始并从那里开始逐步发展是​​最富有成效的。我们的目标是发现简单的算法模式、主题或框架，然后将其应用于更大、更复杂的模型。具体来说，在本文中，我们将研究两层或更少的 Transformer，它们仅具有注意力块 ——这与像 GPT-3 这样的大型现代Transformer形成鲜明对比，GPT-3 有 96 层，并用 MLP 块交替注意力块。

我们发现，通过以一种新的但数学上等效的方式概念化Transformer的操作，我们能够理解这些小模型，并深入了解它们的内部操作方式。特别值得注意的是，我们发现我们称之为“归纳头”的特定注意力头可以解释这些小模型中的上下文学习，并且这些头仅在具有至少两个注意力层的模型中发展。我们还介绍了这些头对特定数据进行操作的一些示例。

在第一篇论文中，我们并不试图将我们的见解应用于更大的模型，而是在 即将发表的论文，我们将证明，我们用于理解Transformer的数学框架和归纳头的概念，仍然至少部分地与更大、更现实的模型相关——尽管我们距离能够完全逆向工程此类模型还有很长的路要走。






结果摘要

逆向工程结果

为了探索Transformer逆向工程的挑战，我们对几个玩具、仅含注意力的模型进行了逆向工程。这样做我们发现：

  • 零层Transformer模型二元组统计。 二元组表可以直接从权重访问。
  • 单层注意力Transformer是 an 二元模型和“跳跃三元模型”（“A…B C”形式的序列）模型的集合。 二元模型和跳跃三元模型表可以直接从权重访问，无需运行模型。这些跳跃三元语法的表现力令人惊讶。这包括实施一种非常简单的情境学习。
  • 两层纯注意力 Transformer可以使用注意头的组合来实现更复杂的算法。 这些合成算法也可以直接从权重中检测出来。值得注意的是，两层模型使用注意力头组合来创建“归纳头”，这是一种非常通用的上下文学习算法。[1]
  • 一层和两层纯注意力 Transformer使用非常不同的算法来执行上下文学习。两层注意力头使用质量上更复杂的推理时间算法（特别是我们称为归纳头的特殊类型的注意力头）来执行上下文学习，形成与更大模型相关的重要过渡点。

概念要点

我们发现Transformer架构的许多微妙细节要求我们以与 InceptionV1 回路 [7] 工作方式截然不同的方式对其进行逆向工程。我们将在下面的部分中逐一展开，但现在我们简要总结一下。一旦我们到达适当的部分，我们还将扩展这里介绍的许多术语。 （需要明确的是，我们并不打算声称这些观点中的任何一个都一定是新颖的；许多观点隐含或明确地存在于其他论文中。）

  • Attention Heads 可以理解为独立的操作，每个输出一个结果，该结果被添加到残差流中。 Attention Heads 通常以替代的“连接和乘法”公式来描述，以提高计算效率，但这在数学上是等效的。
  • 仅注意模型可以编写为可解释的端到端函数 将标记映射到 logits 变化的总和。这些函数对应于模型的“路径”，如果冻结注意力模式，它们是线性的。
  • Transformers 具有大量的线性结构。 只需通过分解和并将矩阵链相乘就可以学到很多东西。
  • 注意力头可以理解为具有两个很大程度上独立的计算：计算注意力模式的 QK（“查询键”）回路和计算每个标记在关注时如何影响输出的 OV（“输出值”）回路。
  • 键、查询和值向量可以被视为低秩矩阵 WQTWKW_Q^TW_K 和 WOWVW_OW_V 计算中的中间结果。在不参考Transformer的情况下描述Transformer可能会很有用。
  • 注意力头的组成极大地增加了 Transformer 的表现力。注意力头可以采用三种不同的方式组成，分别对应于键、查询和值。键和查询组合与值组合有很大不同。
  • Transformer的所有组件（令牌嵌入、注意力头、MLP 层和非嵌入）通过读取和写入残差流的不同子空间来相互通信。与其分析残差流向量，不如将残差流分解为所有这些不同的通信通道（对应于通过模型的路径）。





Transformer概述

在我们尝试对 Transformer 进行逆向工程之前，简要回顾一下 Transformer 的高级结构并描述我们如何看待它们会很有帮助。

在许多情况下，我们发现以等效但非标准的方式重新构建Transformer很有帮助。机制可解释性要求我们将模型分解为人类可解释的部分。重要的第一步是找到最容易推理模型的表示形式。在现代深度学习中，这是有充分理由的！ - 非常强调计算效率，我们对模型的数学描述通常反映了如何编写有效代码来运行模型的决策。但是，当有许多等效的方法来表示相同的计算时，最容易被人类解释的表示和计算上最有效的表示很可能会有所不同。

审查Transformer还可以让我们在术语上保持一致，这些术语有时可能会有所不同。我们还将在此过程中介绍一些符号，但由于该符号在许多部分中使用，因此我们在 符号附录 中提供了所有符号的详细描述，作为读者的简明参考。

模型简化

为了以最简洁的形式展示本文中的想法，我们重点关注经过一些简化的“玩具变形金刚”。

在本文的大部分内容中，我们将做出非常实质性的改变：我们关注“仅注意”Transformer，它没有 MLP 层。这是Transformer架构的一个非常显着的简化。我们的部分动机是，带有注意力头的回路提出了 Distill 回路工作所没有面临的新挑战，并且单独考虑它们使我们能够对这些问题给出特别优雅的处理。但到目前为止，我们在理解 MLP 层方面还没有取得多少成功。在具有注意力层和 MLP 层的普通 Transformer 中，有许多主要由注意力头介导的回路，我们可以研究它们，其中一些看起来非常重要，但 MLP 部分更难获得关注。这是我们工作的一个主要弱点，我们计划在未来重点解决。尽管如此，我们仍将在后面的部分中讨论具有 MLP 层的转换器。

我们还做了一些我们认为比较肤浅的更改，主要是为了清晰和简单。我们不考虑偏差，但是通过将偏差折叠到权重中并创建始终为一的维度，可以在没有偏差的情况下模拟具有偏差的模型。此外，纯注意力 Transformer中的偏差在功能上大多会乘以对数偏差。我们还忽略了层归一化。它增加了相当多的复杂性来明确考虑，并且在可变缩放范围内，层范数可以合并到相邻权重中。我们还期望，除了一些实现上的烦恼之外，层范数可以代替批量归一化（它可以完全折叠到相邻参数中）。

高层架构

Transformer 语言模型有多种变体。我们专注于自回归、仅解码器的 Transformer 语言模型，例如 GPT-3。 （最初的 Transformer 论文有一个特殊的编码器-解码器结构来支持翻译，但许多现代语言模型不包括这一点。）

Transformer从令牌嵌入开始，然后是一系列“剩余块”，最后是令牌取消嵌入。每个残差块由一个注意力层和后面的 MLP 层组成。注意力层和 MLP 层均从残差流中“读取”其输入（通过执行线性投影），然后通过添加线性投影将其结果“写入”残差流。每个注意力层由多个头组成，这些头并行运行。

虚拟权重和残差流作为通信通道

Transformer 高级架构的主要特征之一是每一层都将其结果添加到我们所说的“残差流”中。[2] 残差流只是所有先前层的输出与原始嵌入的总和。我们通常将残差流视为通信通道，因为它本身不进行任何处理，并且所有层都通过它进行通信。

残差流具有深度线性结构。[3] 每层都执行任意线性变换以在开始时从残差流中“读入”信息，[4] 并在添加将其输出“写”回残差流之前执行另一个任意线性变换。残差流的这种线性、加性结构具有许多重要的含义。一个基本的结果是残差流没有“特权基础”；我们可以通过旋转与其交互的所有矩阵来旋转它，而不改变模型行为。

虚拟权重

残差流是线性的一个特别有用的结果是，人们可以认为隐式“虚拟权重”直接连接任何一对层（甚至是那些被许多其他层分隔的层），通过将它们的相互作用与残差流相乘。这些虚拟权重是一层的输出权重与另一层的输入权重[5]（即WI2WO1W_{I}^2W_{O}^1）的乘积，并描述后面的层读取前一层写入的信息的程度。

子空间和残差流带宽

残差流是一个高维向量空间。在小型模型中，可能有数百个维度；在大型模型中，它可以达到数万个。这意味着层可以通过将不同的信息存储在不同的子空间中来将不同的信息发送到不同的层。这对于注意力头来说尤其重要，因为每个单独的头都在相对较小的子空间（通常是 64 或 128 维）上运行，并且可以很容易地写入完全不相交的子空间并且不交互。

添加后，信息将保留在子空间中，除非另一层主动删除它。从这个角度来看，残差流的维度就变成了“内存”或“带宽”之类的东西。原始的令牌嵌入以及未嵌入大多与相对较小的维度交互。[6] 这使得大多数维度“自由”供其他层存储信息。

看来我们应该预计残差流带宽的需求非常高！通常，“计算维度”（例如神经元和注意力头结果维度）远多于残差流移动信息的维度。单个 MLP 层的神经元数量通常是残差流维度的四倍。因此，例如，在 50 层 Transformer 的第 25 层，残差流的神经元数量是其之前维度的 100 倍，尝试与其之后维度的 100 倍神经元进行通信，以某种方式以叠加方式进行通信！我们将像 这样的张量称为“瓶颈激活”，并期望它们的解释异常困难。 （这就是为什么我们会尝试根据虚拟权重将通过残差流发生的不同通信流分开，而不是直接研究它。）

也许是因为对残差流带宽的高要求，我们已经看到一些MLP神经元和注意力头可能执行一种“内存管理”角色的暗示，通过读入信息并写出负版本来清除其他层设置的残差流维度。[7]

注意力头如何搬运信息

但如果注意力头独立行动，它们会做什么？注意头的基本动作是移动信息。他们从一个令牌的残差流中读取信息，并将其写入另一个令牌的残差流中。从本节中得出的主要观察结果是，从哪些令牌移动信息与“读取”要移动的信息以及如何将其“写入”目的地完全分开。

要看到这一点，以非标准方式编写注意力是有帮助的。给定一个注意力模式，计算注意力头的输出通常分为三个步骤：

  1. 计算残差流中每个标记的值向量 (vi=WVxiv_i = W_V x_i)。
  2. 根据注意力模式（ri=∑jAi,jvjr_i = \sum_j A_{i,j} v_j）线性组合值向量来计算“结果向量”。
  3. 最后，计算每个标记的头部的输出向量（h(x)i=WOrih(x)_i = W_O r_i）。[8]

关于注意力头的观察

以这种形式重写注意力头的一个主要好处是它显示了许多以前可能难以观察的结构：

  • 注意力头将信息从一个令牌的残差流移动到另一个令牌。
  • 其推论是，残差流向量空间（通常被解释为“上下文词嵌入”）通常具有与从其他标记复制的信息相对应的线性子空间，而不是直接与当前标记相关的信息。
  • 注意力头实际上应用了两个线性运算，AA 和 WOWVW_OW_V，它们在不同的维度上运算并独立运行。
  • AA 控制从哪个令牌的信息移动到哪个令牌。
  • WOWVW_O W_V 控制从源令牌读取哪些信息以及如何将其写入目标令牌。[9]
  • AA 是该方程中唯一的非线性部分（根据 softmax 计算）。这意味着如果我们固定注意力模式，注意力头就会执行线性操作。这也意味着，在不固定 AA 的情况下，注意力头在某种意义上是“半线性”的，因为每个令牌的线性操作是恒定的。
  • WQW_Q 和 WKW_K 始终一起运行。他们从来都不是独立的。同样，WOW_O 和 WVW_V 也始终一起运行。
  • 尽管它们被参数化为单独的矩阵，但 WOWVW_O W_V 和 WQTWKW_Q^T W_K 始终可以被视为单独的低秩矩阵。
  • 从某种意义上说，键、查询和值向量都是肤浅的。它们是计算这些低阶矩阵的中间副产品。人们可以轻松地重新参数化低秩矩阵的两个因子以创建不同的向量，但功能仍然相同。
  • 因为 WOWVW_O W_V 和 WQWKW_Q W_K 总是一起运算，所以我们喜欢定义代表这些组合矩阵 WOV=WOWVW_{OV} = W_O W_V 和 WQK=WQTWKW_{QK} = W_Q^T W_K 的变量。
  • 注意力头产品的行为与注意力头本身非常相似。由分配性质，(Ah2⊗WOVh2)⋅(Ah1⊗WOVh1)(A^{h_2}\otimes W_{OV}^{h_2}) \cdot (A^{h_1}\otimes W_{OV}^{h_1}) =(Ah2Ah1)⊗(WOVh2WOVh1)= (A^{h_2}A^{h_1})\otimes(W_{OV}^{h_2}W_{OV}^{h_1})。该产品的结果可以被视为在功能上等同于一个注意力头，其注意力模式是由两个头 Ah2Ah1A^{h_2}A^{h_1} 和一个输出—值矩阵 WOVh2WOVh1W_{OV}^{h_2}W_{OV}^{h_1} 组成。我们将这些称为“虚拟注意力头”，稍后将进行更深入的讨论。

在继续讨论更复杂的模型之前，简要考虑一下“零层”Transformer是很有用的。这样的模型采用一个标记，嵌入它，取消嵌入它以生成预测下一个标记的逻辑：

T = WUWET ~=~ W_U W_E

由于模型无法从其他标记中移动信息，因此我们只是根据当前标记来预测下一个标记。这意味着 WUWEW_U W_E 的最佳行为是近似二元对数似然。[10]

这与更广泛的Transformer相关。 WUWEW_U W_E 形式的项将出现在每个Transformer的方程的扩展形式中，对应于“直接路径”，其中令牌嵌入直接沿着残差流流向非嵌入，而不经过任何层。它唯一可以影响的是二元对数似然。由于模型的其他方面将预测二元对数似然的部分，因此它不会准确地代表较大模型中的二元统计，但它确实代表了一种“残差”。特别是，WUWEW_U W_E 术语似乎经常有助于表示更通用的语法规则无法描述的二元统计数据，例如“Barack”后面经常跟着“Obama”这一事实。 [11]






单层纯注意力 Transformer

我们声称单层纯注意力 Transformer可以理解为二元模型和几个“跳过三元”模型（影响序列“A…BC”的概率）的集合。[12] 直观上，这是因为每个注意力头可以选择性地关注从当前令牌（“B”）到前一个令牌（“A”）并复制信息以调整可能的下一个令牌（“C”）的概率。

本节的目标是严格展示这种对应关系，并演示如何将转换器的原始权重转换为可解释的跳跃三元语法概率调整表。

路径扩展技巧

回想一下，单层纯注意力 Transformer由令牌嵌入组成，然后是注意层（ 独立应用 注意力头），最后是非嵌入：

使用我们之前导出的 张量符号 和 注意力头的替代表示 ，我们可以将Transformer表示为三项的乘积。

我们的关键技巧是简单地扩展产品。这会将乘积（其中每项对应一个层）转换为 a 总和，其中每项对应一条端到端路径 。

我们声称这些端到端路径术语中的每一个都易于理解，可以独立推理，并且可以相加地组合以创建模型行为。

当我们查看零层Transformer时，也出现了直接路径项 Id⊗WUWE\text{Id} \otimes W_U W_E。因为它不会在位置之间移动信息（这就是 Id⊗…\text{Id} \otimes … 所表示的！），所以它唯一可以贡献的是二元组统计数据，并且它将填补其他术语无法处理的缺失空白。

更有趣的术语是注意力头术语。

将注意力头项分解为查询键和输出值回路

对于每个注意力头 hh，我们有一个术语 Ah⊗(WUWOVhWE)A^h \otimes (W_UW_{OV}^hW_E)，其中 Ah=A^h= softmax(tT⋅WETWQKhWE⋅t)\text{softmax}\left( t^T \cdot W_E^T W_{QK}^h W_E \cdot t \right)。我们如何将这些术语映射到模型行为？当我们这样做时，为什么我们的方程会得到这些特定的矩阵乘积？

需要注意的关键是，这些项由两个可分离的运算组成，其核心是两个 [nvocab, nvocab][n_\text{vocab},~ n_\text{vocab}] 矩阵：

  • WETWQKhWEW_E^T W_{QK}^h W_E — 我们将此矩阵称为“查询键 (QK) 回路”。它提供每个查询和关键令牌的注意力分数。也就是说，每个条目描述给定查询令牌“想要”参与给定密钥令牌的程度。
  • WUWOVhWEW_UW_{OV}^hW_E — 我们将此矩阵称为“输出值 (OV) 回路”。它描述了如果注意的话给定的标记将如何影响输出 logits。

为了直观地理解这些产品，将它们视为穿过模型的路径（从标记开始和结束）会很有帮助。 QK 回路是通过跟踪查询和密钥向量的计算直至其注意力头而形成的，在此处它们进行点积以创建双线性形式。 OV 回路是通过跟踪计算值向量的路径并将其继续直至 logits 来创建的。

注意力模式是源令牌和目标令牌 [13] 的函数，但是一旦目标令牌决定了对源令牌的关注程度，对输出的影响就仅是该源令牌的函数。也就是说，如果多个目标令牌对同一源令牌进行相同数量的处理，则源令牌将对预测输出令牌的 logits 产生相同的影响。

OV 和 QK 独立（冻结注意力模式技巧）

单独考虑 OV 和 QK 回路非常有用，因为它们都是我们可以理解的单独函数（在我们理解的矩阵上运行的线性或双线性函数）。

但独立思考真的有原则吗？一项可能有用的思想实验是想象运行模型两次。第一次收集每个头的注意力模式。这仅取决于 QK 回路。[14] 第二次，您将注意力模式替换为第一次收集的“冻结”注意力模式。这为您提供了一个函数，其中 logits 是标记的线性函数！我们发现这是一种非常有力的思考 Transformer 的方式。

解释为跳跃三元语法

机制可解释性的核心挑战之一是通过上下文化来使神经网络参数变得有意义（参见 Voss et al. 在 Visualizing Weights [8] 中的讨论）。通过将 OV 和 QK 回路相乘，我们成功地做到了这一点：神经网络参数现在是令牌上的简单线性或双线性函数。 QK 回路确定当前“目标”令牌返回哪个“源”令牌并从中复制信息，而 OV 回路则描述对下一个令牌的“输出”预测产生的影响。所涉及的三个标记一起形成了 [source]... [destination][out] 形式的“skip-trigram”，并且“out”被修改。

值得注意的是，这并不意味着解释是微不足道的。一方面，生成的矩阵非常巨大（我们的词汇量约为 50,000 个标记，因此单个扩展 OV 矩阵具有约 25 亿个条目）；我们揭示了单层注意力模型是一个压缩的中文房间，我们留下了一大堆卡片。理解作用于相关变量的广义线性模型的权重以及变量之间的可替代性还存在所有常见问题。例如，一个注意力头的权重可能为零，因为另一个注意力头将关注相同的令牌并执行其应具有的相同角色。最后，还有一个技术问题，即不同查询向量之间的 QK 权重不具有可比性，并且对于如何标准化它们也没有明确的正确答案。

尽管如此，我们确实有一种形式的转换器，其中所有参数都是上下文相关且易于理解的。尽管存在这些微妙之处，我们仍然可以简单地从联合 OV 和 QK 矩阵中读取跳跃三元语法。特别是，在这些矩阵中搜索大型条目会发现许多有趣的行为。

我们还看到了更微妙的复制行为。一个特别有趣的问题与Transformer的标记化通常如何工作有关。分词器通常将空格合并到单词的开头。但有时某个单词会出现在其前面没有空格的上下文中，例如在新段落的开头或对话开放引用之后。这些情况很少见，因此标记化并未针对它们进行优化。因此，对于不太常见的单词，当它们前面有空格时 (" Ralph" → [" Ralph"]) 映射到单个标记，但当没有空格时 ("Ralph" → ["R", "alph"]) 则拆分，这是很常见的。

在这种情况下，处理复制的跳过三元组条目是很常见的。事实上，我们有时会观察到注意力头似乎部分专门处理分裂成两个没有空格的标记的单词的复制。当这些注意力头观察碎片标记（例如，"R"）时，它们会回想起可能是带有空格的完整单词（" Ralph"）的标记，然后预测延续（"alph"）。 （有趣的是，这可以被认为是一种非常特殊的情况，其中单层模型可以模仿我们将在两层模型中看到的 归纳头 。）

跳跃三元语法中的缺陷

查看一层Transformer的扩展 QK 和 OV 矩阵最有趣的事情之一是，它们可以揭示从外部看来难以理解的Transformer行为。

我们的单层模型以 OV 和 QK 矩阵之间的“因式分解形式”表示跳跃三元语法。这有点像代表一个函数 f(a,b,c)=f1(a,b)f2(a,c)f(a,b,c) = f_1(a,b) f_2(a,c)。他们无法真正灵活地捕捉三向交互。例如，如果单个头增加了两个头的概率 keep… in mind 和 keep… at bay, 它 必须 也增加了概率 keep… in bay 和 keep… at mind。总的来说，这对于模型来说可能是一笔不错的交易，但从某种意义上来说，这也是一个错误。我们经常在注意力集中观察到这些。

总结 OV/QK 矩阵

我们已经将理解单层注意力变换器的问题转化为理解其扩展 OV 和 QK 矩阵的问题。但如上所述，扩展后的 OV 和 QK 矩阵非常庞大，有数十亿个条目。虽然搜索最大的条目很有趣，但有更好的方法来理解它们吗？至少有以下三个理由值得期待：

  • OV 和 QK 矩阵的秩极低。它们是 50,000 × 50,000 矩阵，但排序仅为 dheadd_\text{head}（64 或 128）。从某种意义上说，尽管它们在展开后看起来很大，但它们仍然很小。
  • 查看各个条目通常会发现结构简单得多的迹象。例如，我们观察到一个头部，其中人名都具有 " by"（例如，"Anne… by → Anne"）等热门查询，而位置名称具有 " from"（例如，"Canada… from → Canada"）等热门查询。这暗示了矩阵中的簇结构。
  • 复制行为在 OV 矩阵中很普遍，并且可以说是最有趣的行为之一。 （我们将在下一节中看到，两层模型中有类似的 QK 矩阵结构，用于搜索与查询相似的标记。）似乎应该可以将其形式化。

我们还没有找到明确的正确答案，但我们乐观地认为，正确的矩阵分解或降维可能会提供大量信息。 （有关如何有效处理这些大型矩阵的说明，请参阅技术细节附录。）

检测复制行为

我们最高兴能够以自动方式检测到的行为类型是复制。由于复制从根本上讲是将相同的向量映射到自身（例如，拥有一个标记会增加其自身的概率），因此它似乎非常适合在某种汇总统计中捕获。

然而，我们发现很难准确地确定正确的概念是什么。这可能是因为有很多稍微不同的方法可以用来界定某物是否是“复制矩阵”的界限，而我们还不确定最有用的方法是什么。例如，我们在本文讨论的模型中没有观察到这一点，但在稍大的模型中，我们经常观察到注意力头，它从附近的单词中“复制”一些性别、复数和时态的混合，帮助模型使用正确的代词和共轭动词。这些注意力头的矩阵并不完全复制单个标记，但它们似乎是在某种非常有意义的意义上复制。因此，复制实际上是一个比乍看起来更复杂的概念。

但是，虽然复制矩阵必须具有正特征值，但尚不清楚所有具有正特征值的矩阵都是我们必须考虑复制的矩阵。矩阵的特征向量不一定是正交的，这允许病态的例子；例如，[18]，可以存在具有所有正特征值的矩阵，这些矩阵实际上映射一些标记以减少同一标记的对数。正特征值仍然意味着矩阵在某种意义上是“平均复制”，并且它们仍然是复制的有力证据，因为默认情况下它们似乎不太可能，并且从经验上看似乎与复制一致。但它们不应该被视为矩阵在所有合理意义上的复制的决定性证据。

人们可能会尝试以其他方式形式化“复制矩阵”。一种可能性是查看矩阵的对角线，它描述了每个标记如何影响其自身的概率。正如预期的那样，对角线上的条目非常积极。我们还可以问，随机标记比任何其他标记增加其自身概率的频率有多高（或者是 k 个增加最多的标记之一，以允许具有不同大小写或空格的相同标记）。所有这些似乎都指向这些注意力头正在复制矩阵的方向，但尚不清楚它们中的任何一个是否是“该矩阵的主要行为是复制”的完全稳健的形式化。值得注意的是，所有这些潜在的复制概念都与特征值之和等于迹等于对角线之和这一事实相关联。

出于本文的目的，我们将继续使用基于特征值的汇总统计量。我们认为它并不完美，但它似乎是复制的有力证据，并且在经验上与手动检查和其他定义一致。

我们“完全理解”单层模型吗？

人们常常怀疑是否有可能或值得尝试真正对神经网络进行逆向工程。在这种情况下，人们很容易指向单层注意力Transformer并说“看，如果我们采用最简化的玩具版本的Transformer，至少可以完全理解最小版本。”

但这种说法实际上取决于人们所说的完全理解是什么意思。在我们看来，我们现在理解这个简化模型的意义就像我们可以查看一个巨大的线性回归的权重并理解它，或者查看一个大型数据库并理解查询它意味着什么。这是一种理解。不再有任何算法之谜。神经网络参数的情境化问题已被剥离。但如果不进一步进行总结，人们就无法在头脑中记住这个模型。

考虑到常规的一层神经网络只是广义线性模型并且可以这样解释，因此单个注意力层大多也是一个也就不足为奇了。






双层纯注意力 Transformer

深度学习研究的模型是 deep，也就是说它们有很多层。从经验来看，这样的模型非常强大。这个力量从哪里来？一种直觉可能是深度允许构图，从而创造强大的表现力。

注意力头的组成是一层和两层仅注意力Transformer之间的主要区别。如果没有组合，两层模型就会有更多的注意力头来实现跳跃三元语法。但我们会看到，在实践中，两层模型发现了利用注意力头组合的方法来表达一种更强大的机制来完成上下文学习。这样做时，它们变得更像是运行算法的计算机程序，而不是我们在单层模型中看到的跳跃三元语法查找表。

三种组合

回想一下，我们将残差流 视为通信通道 。每个注意力头读取由WQW_Q、WKW_K和WVW_V确定的残差流的子空间，然后写入由WOW_O确定的某个子空间。由于注意力头向量远小于残差流的大小（dhead/dmodeld_\text{head} / d_\text{model} 的典型值可能在 1/101/10 到 1/1001/100 之间变化），因此注意力头在较小的子空间上运行，可以轻松避免显着的交互。

当注意力头开始撰写时，有以下三种选择：

  • Q-Composition：WQW_Q 读入受前一个头影响的子空间。
  • K-组合：WKW_K 读入受前一个头影响的子空间。
  • V-Composition：WVW_V 读入受前一个头影响的子空间。

Q-和K-组合与V-组合有很大不同。 Q-和 K-Composition 都会影响注意力模式，使注意力头能够表达更复杂的模式。另一方面，V-Composition 会影响注意力头在关注给定位置时移动的信息；结果是，V 形组合的头部实际上更像是一个单元，并且可以被认为是创建了一个额外的“虚拟注意力头部”。将信息的运动与信息的运动相结合给出了信息的运动，而影响注意力模式的注意力头不能以这种方式还原。

要真正理解这三种组成，我们需要再次研究OV和QK回路。

术语重要性分析

早些时候，我们决定忽略所有“虚拟注意力头”术语，因为我们没有观察到任何重要的 V 组合。虽然这看起来可能是正确的，但我们在某些方面可能会犯错。特别是，虽然每个单独的虚拟注意力头并不重要，但它们总的来说很重要。本节将描述一种使用消融来双重检查的方法。

通常，当我们在神经网络中消融某些东西时，我们正在消融在激活中明确表示的某些东西。我们只需将其乘以零即可。但在这种情况下，我们试图消除一个仅在展开方程时才存在的隐式项。我们可以通过尝试运行方程中描述的Transformer版本来做到这一点，但这会非常慢，而且当我们考虑更深的模型时，情况会呈指数级恶化。

但事实证明，有一种算法可以确定消除 nn 阶项（即与通过 nn 注意力头的 V 组合的路径相对应的项）的边际效应。关键技巧是多次运行模型，将当前的激活替换为之前运行模型时的激活。这允许人们限制路径的深度，消除所有大于该深度的阶项。然后，通过计算每次消融观察到的损失之间的差异，我们可以获得 nn 阶项的边际效应。

测量边际损失减少的算法 nn三阶项
步骤一： 运行模型，保存所有注意力模式。
步骤2： 运行模型，强制所有注意力模式成为您记录的版本，而不是将注意力头输出添加到残差流中，而是保存输出，然后将其替换为相同形状的零张量。记录由此产生的损失。
步骤 nn: 运行模型，强制所有注意力模式成为您记录的版本，而不是将注意力头输出添加到残差流中，而是保存输出，并将其替换为您上次为此头保存的值。记录由此产生的损失。

（请注意，将注意力模式冻结到真实值使得这种消融仅针对 V 组合。尽管这在某些方面是最简单的算法，专注于 OV 回路，但该算法的变体也可用于隔离 Q 或 K 组合。）

正如 V 组合结果所示，二阶“虚拟注意力头”项在此模型中的边际效应非常小。 （尽管它们在其他模型（尤其是较大的模型）中很可能更为重要。）

我们的结论是，为了理解双层仅注意力模型，我们不应该优先考虑理解二阶“虚拟注意力头”，而应该关注直接路径（只能有助于二元组统计）和个体注意力头项。 （我们强调，这与 Q-和 K-Composition 无关；OV 回路中的高阶项并不重要，只是排除了 V-Composition 的重要性。Q-和 K-Composition 对应于每个头的 QK 回路中的项。）

虚拟注意力头

尽管事实证明虚拟头对于理解两层模型的性能相当不重要，但我们推测这些在更大、更复杂的Transformer中可能更为重要。我们也对它们感到震惊，因为它们在理论上看起来非常优雅。

回想一下，虚拟注意力头是 Logit 方程路径展开中 (Ah2Ah1)⊗(…WOVh2WOVh1…)(A^{h_2}A^{h_1}) \otimes (\ldots W_{OV}^{h_2}W_{OV}^{h_1}\ldots) 形式的项，对应于两个头的 V 组合。

Q-Composition 和 K-Composition 影响注意力模式，而 V-Composition 创建这些术语，它们实际上作为一种独立单元运行，先执行一个头部操作，然后执行另一个头部操作。这个结果对象实际上最好被认为是头部的组合，h2∘h1h_2 \circ h_1。它有自己的注意力模式 Ah2∘h1=Ah2Ah1A^{h_2 \circ h_1} = A^{h_2}A^{h_1} 和自己的 OV 矩阵 WOVh2∘h1=WOVh2WOVh1W_{OV}^{h_2 \circ h_1} = W_{OV}^{h_2}W_{OV}^{h_1}。在更深的模型中，原则上可以具有更高阶的虚拟注意力头（例如，h3∘h2∘h1h_3 \circ h_2 \circ h_1）。

关于虚拟注意力头，有两件事值得注意。

首先，这样的构图看起来很有力量。我们经常看到注意力模式关注前一个令牌的头，而不是关注后面两个令牌的头——这可能是因为来自后面两个令牌的任何有用的预测能力都是通过虚拟头获得的。注意力模式还可以实现更抽象的东西，例如关注当前子句的开头或句子的主语——组合可以实现“关注前一个子句的主语”等功能。

其次，有一个 lot of 虚拟注意力头。正常头部的数量随层数线性增长，而基于两个头部组成的虚拟头部的数量呈二次方增长，在三个头部上呈立方体增长等。这意味着模型理论上可能有更多的空间通过虚拟注意力头获得有用的预测能力。这一点尤其重要，因为正常的注意力头在某种意义上是“大的”。头部有一个单一的注意力模式来确定它关注哪些源令牌，以及从源令牌复制到目标令牌的 dheadd_{\text{head}} 维度。这使得它难以用于不需要传达太多信息的直观“小”任务，例如，关注先前的代词来确定文本是第一人称、第二人称还是第三人称，或者关注时态标记来检测文本是过去、现在还是将来的文本。






这给我们带来了什么？

在过去的几节中，我们在理解一层和两层注意力Transformer方面取得了进展。但我们的最终目标是总体了解Transformer。这项工作真的拉近了我们的距离吗？这些特殊的、有限的案例真的能说明普遍问题吗？我们将在后续工作中探讨这个问题，但我们的总体感觉是，是的，这些方法可以用来理解通用 Transformer 的 portions，包括大型语言模型。

原因之一是普通Transformer包含一些看起来为的回路，主要注意。即使存在 MLP 层，注意力头仍然对残差流进行操作，并且仍然可以直接相互交互以及与嵌入交互。在实践中，我们发现可解释回路的实例仅涉及注意力头和嵌入。尽管我们可能无法理解整个模型，但我们非常有能力对这些部分进行逆向工程。

事实上，我们实际上在大型模型中看到了一些与我们在这些玩具模型中分析的类似的注意力头和回路！特别是，我们会发现大型模型形成许多归纳头，并且其构造的基本构建块是与先前令牌头的 K 组合，正如我们在这里看到的那样。这似乎是各种规模的语言模型中上下文学习的核心驱动力——我们将在下一篇论文中讨论这个主题。

也就是说，我们可能只能通过这种方式理解一小部分大型语言模型。一方面，MLP 层占标准Transformer参数的 2/3。显然，如果不了解这些参数，我们将无法理解模型的大部分行为。事实上情况可能更糟：因为许多注意力头与 MLP 层交互，所以在不考虑 MLP 层的情况下我们可以理解的参数比例甚至小于 1/3。更完整的理解需要在 MLP 层上取得进展。在机械层面上，他们的回路实际上具有非常好的数学结构（参见附加直觉）。然而，最清晰的前进道路需要单独可解释的神经元，而我们在这方面的成功发现有限。

最终，我们在这篇最初的论文中的目标只是为未来解决这个问题的努力奠定一个立足点。未来仍有许多工作要做。






相关工作

回路

Distill Circuits thread [7] 是对 InceptionV1 模型进行逆向工程的共同努力。我们的工作旨在为大型语言模型做类似的事情。

回路方法需要在语言模型的背景下进行重大重新思考。注意力头与卷积网络中的任何东西都非常不同，需要一种新的方法。残差流的线性结构既带来了新的挑战（缺乏特权基础消除了研究它的一些选择），也创造了机会（我们可以通过它进行扩展）。拥有双线性形式而不仅仅是线性的回路也是相当不寻常的（尽管 Goh et al.[12] 研究了图像和语言模型之间的双线性交互）。

我们注意到 InceptionV1 上的原始回路与仅注意 Transformer 语言模型中的研究回路之间存在一些有趣的高级差异：

  • 仅注意模型的回路分析可能随模型大小的变化而有很大不同。在仅注意模型中，参数被排列在与注意头相对应的相对较大、有意义、很大程度上线性操作的块中。这创造了很多“粗略理解”大量参数的机会。即使非常大的模型也只有几千个注意力头——在这样的规模下，观察每一个注意力头似乎是合理的。当然，一旦添加 MLP 层，大多数参数都在其中，这对于理解模型来说相对较小。
  • 与尝试研究小视觉模型中的回路相比，我们在研究微型纯注意力 Transformer中的回路方面取得了更大的成功。在小视觉模型中，问题在于神经元通常是不可解释的。这里似乎没有发生类似的情况，因为我们可以将所有内容简化为端到端术语。然而，也许当我们更仔细地研究具有 MLP 层的模型（不能简化为端到端术语）时，我们还会发现需要规模来使神经元可解释。

Logit 镜头

LessWrong 用户 Nostalgebraist 之前的工作是他们称之为 “Logit Lens”[13] 的方法，探索了我们大量利用的残差流的相同线性结构。 Logit 透镜方法指出，由于残差流是迭代细化的，因此可以将反嵌入矩阵应用于残差流的早期阶段（即本质上查看 WUxiW_U x_i），以查看模型预测在某种意义上如何演变。

我们的方法可以被视为进行类似的观察，但决定残差流实际上并不是研究的基本对象。由于它是许多注意力头和神经元的线性投影的总和，因此很自然地简单地乘以权重来查看对总和做出贡献的所有不同部分如何与逻辑联系起来。然后，我们可以继续利用线性结构，并尝试将线性尽可能地推回到模型中，这大致将我们的方法引入其中。

注意力头分析

我们的工作遵循了之前几篇研究Transformer注意力头的论文的思路。对注意力模式的研究可能始于 Llion Jones [14] 的可视化，并迅速被其他人 [15] 扩展。最近，有几篇论文开始认真研究注意力头和语法结构 [16][17][18] 之间的对应关系。

之前对注意力头的分析与我们的工作之间最大的区别似乎确实是目标问题：我们寻求提供端到端的机械解释，而不是凭经验描述注意力模式。当然，这篇初步论文也与之前的工作不同，因为我们只研究了非常小的玩具模型，然后才真正说明和支持我们的理论。最后，我们关注自回归Transformer，而不是像 BERT [19] 这样的去噪模型。

我们的调查受益于之前的这些论文，对于我们的结果与它们的关系，我们有一些不同的想法：

  • 与大多数此类论文一样（，例如，[16][17]），我们在大多数模型中观察到先前令牌注意力头的存在。有时，在小型模型中，我们会得到一个注意力头，它在最后两个或三个标记上更加模糊。
  • 我们反映了其他人的发现，即许多注意力头似乎使用标点符号或特殊标记作为默认值（例如 ， [15][17]）。归纳头提供了一个具体的例子。与 Kobayashi et al. [11] 类似，我们发现通过值向量的大小来缩放注意力模式对于澄清这一点非常有帮助。
  • 本文讨论的玩具模型没有表现出先前一些工作所描述的复杂的语法注意头。然而，我们确实在较大的模型中发现了更多类似的注意力头。
  • Voita et al. [16] 描述了优先关注稀有令牌的注意力头；我们想知道这些是否与我们描述的跳跃三元语法注意力头相似。
  • 有几篇论文指出了注意力头的存在，它关注先前对当前令牌的引用。我们突然想到，我们所说的“归纳头”可能会出现在基于屏蔽数据训练的双向模型中，而不是自回归模型中（机械签名将是具有较大正特征值的 QK 展开中的 Ahprev⊗Ahprev⊗WA^{h_{prev}} \otimes A^{h_{prev}} \otimes W）。

对注意力的批评作为解释

一项重要的工作批评了对注意力权重的幼稚解释，即描述给定标记对影响模型输出的重要性（ 经验性地参见 [20][21]；例如 相关概念讨论， [22][23];，但请参见 [24])。

我们的框架可能被认为是为仅注意模型的有限情况提供了一种对注意模式的天真的解释可能产生误导的方式的类型学，以及它们可以正确的具体方式。当注意力头独立行动时，对应于我们方程中的一阶项，它们确实可以直接解释。 （事实上​​，它甚至比这更好：正如我们在单层模型中看到的那样，我们还可以轻松地描述这些一阶项如何影响逻辑！）然而，注意力头可以通过三种方式交互（Q-、K-和 V-Composition）来产生更复杂的行为，这些行为不能很好地映射到注意力模式的天真的解释（对应于Transformer路径扩展中高阶项的爆炸）。问题是这些高阶项有多重要，而且我们已经观察到它们看起来非常重要的情况！

归纳头提供了一个实例教训，说明对注意力模式的天真解释既可以提供大量信息，也可以产生误导。一方面，归纳头本身的注意力模式提供的信息非常丰富；事实上，对于大量的令牌，模型行为可以解释为“归纳头关注前一个令牌并预测它将再次发生”。但是我们发现的归纳头完全依赖于前一层中的先前令牌头，通过 K 组合来确定参加哪里。如果不了解 K 组合效应，人们就会完全误解前一个令牌头的作用，并且也会错过对归纳头如何决定参加哪里的更深入的理解。 （对于考虑基于梯度的归因方法，这也可能是一个有用的测试用例；如果归纳头自信地关注某个地方，其 softmax 将饱和，导致密钥上的梯度较小，从而导致对相应令牌的归因较低，从而掩盖了它所关注的令牌之前的令牌的关键作用。）

Bertology一般

上面提到的注意力头的研究通常被归入一个名为“Bertology”的更大的工作中，该工作研究 Transformer 语言模型表示的内部表示，特别是 BERT [19]。除了注意力头的分析之外，BERT 学研究还有几个方面的探究，其中最大的可能是使用探测方法来探索 BERT 残差流各个阶段的语言特性的工作，在该文献中称为嵌入。不幸的是，我们无法在这里公正地描述 Bertology 的全部范围，而是建议读者参考 Rogers et al. [25] 的 精彩评论 。

我们在本文中的工作主要与 Bertology 的注意力头分析方面相交叉，原因有几个，包括我们对纯注意力模型的关注、我们决定避免直接调查残差流，以及我们对机械而非自上而下的探测方法的关注。

可解释性接口

在我们看来，可解释性研究与支持模型探索的可视化和交互界面密切相关。如果没有可视化，人们就被迫依赖汇总统计数据，并且以如此低维的方式理解像神经网络这样复杂的东西是非常有限的。正确的界面可以让研究人员快速探索各种高维结构：检查注意力模式、激活、模型权重等。当用于提出正确的问题时，界面既支持探索又支持严谨。

机器学习在使用可视化和交互界面来探索模型方面有着悠久的历史（e.g. [57][58][59][60][61][30]）。这在变形金刚的背景下继续存在（e.g. [62][63][64][65]），尤其是注意力的可视化（e.g. [15][66][67]).

  • 其他方向。 Black et al. 探索多面体透镜，这是叠加的替代假设（或至少是透视）。 Millidge et al. 探索权重的 SVD 是否可用于查找可解释的特征方向。
  • 模型试图在 MLP 层中表示哪些特征？ 我们在 MLP 层中发现的一些罕见的可解释神经元上有一个 视频 。 Miller 和 Neo 能够识别单个可解释的“an”神经元。在我们的一篇后续论文中，我们能够在一个设计为具有较少叠加的模型中描述 个看似可解释的神经元 。

注意力头组成和回路。 特纳的 初步研究 更详细地探讨了注意力头组成的想法。 Wang et al. 的一篇论文描述了一个复杂的注意力头回路（但仅在狭窄的子分布上进行了分析）。

Induction Heads. 我们发表了一篇 后续论文 ，探讨归纳头对上下文学习有多大贡献。许多研究人员重现了有关归纳头的一般结果。 Chan et al. 使用他们的“因果擦洗”方法来更严格地表征归纳头。 von Oswald 等人的论文 证明，重复归纳头状机制可以通过模拟梯度下降来学习上下文中的线性模型。与此同时，归纳头越来越多地在“神经网络是否理解”的讨论中被引用，似乎是因为它们是神经网络“实现算法”的一个有趣的具体中间立场（例如，参见 Raphaël Millière 在 这个研讨会 上的演讲）。

MLP层

本文重点关注没有 MLP 层的仅注意力Transformer。我们如何扩展这种方法来理解具有 MLP 层的 MLP 模型？

回想一下，MLP 层 mm 通过执行矩阵乘法并应用其激活函数，从残差流 xix_i 计算其激活 ama^m。然后将激活向量向下投影并添加到残差流中：

GeLU 激活的存在意味着我们无法像处理注意力层那样通过 MLP 层进行线性化。相反，我们可能需要在逆向工程视觉模型中采用回路项目的方法[7]：了解神经元代表什么、如何计算它们以及如何使用它们。

理论上，我们有很多理由对理解这些神经元持乐观态度。它们具有激活函数，可以鼓励特征与基本尺寸保持一致。它们比残差流大四倍，并且信息不需要流过它们，这都是人们可能期望减少多语义性的因素。不幸的是，在实践中事​​情更具挑战性。我们发现，对神经元提出假设要困难得多，但模型深度约为 5% 的神经元除外，它们通常会对具有相似含义的短语簇做出反应。我们将本文的重点放在理解注意力头上，因为我们在注意力头方面获得了更多的早期关注。

尽管如此，值得注意的是，关于如何机械地推理神经元，有一个相当清晰的故事，当我们找到可解释的神经元时，我们可以使用它。

单层模型中MLP层的路径扩展：为了简单起见，让我们考虑一个标准的单层Transformer（忽略层范数和偏差）。预激活值是残差流的线性函数。通过应用我们的注意力头方程，我们得到了与 one 层转换器 logits 基本上相同的方程：

aprem = WIm⋅(Id+∑h∈H1Ah⊗WOVh)⋅ WEa^m_\text{pre} ~=~ W^m_I \cdot \bigg(Id+\sum_{h\in H_1} A^h \otimes W_{OV}^h\bigg)\cdot~W_E

aprem = WImWE + ∑h∈H1Ah⊗(WImWOVhWE)a^m_\text{pre} ~=~ W^m_I W_E ~+~ \sum_{h\in H_1} A^h \otimes \left(W^m_I W_{OV}^h W_E\right)

这意味着我们可以用相同的方法来研究它。 WImWEW^m_I W_E 告诉我们有多少不同的标记通过残差流鼓励或抑制该神经元，而 WImWOVhWEW^m_I W_{OV}^h W_E 如果标记受到给定的注意头的关注，则对标记执行相同的操作。人们可能会认为这与卷积神经网络中的神经元类似，只不过卷积网络中的神经元权重是按相对位置索引的，这些神经元权重是按注意力头索引的。下面的 虚拟权重和类卷积结构 部分将更详细地探讨这种联系。

这些神经元的下游效应又如何呢？ WUWOmW_U W^m_O 告诉我们每个神经元的激活如何影响 logits。这是一个简单的线性函数！ （对于网络的最后一个 MLP 层来说总是如此，并且为理解该层提供了很多额外的牵引力。）

随着网络变得更深，这种方法变得更加困难。人们开始需要推理一个 MLP 层如何影响其下游的另一个层。但一般的电​​路方法似乎很容易处理，除非神经元特别难以理解，而且神经元数量巨大。

虚拟权重和类卷积结构

当我们将路径扩展应用于Transformer中的各个项时，我们通常会得到以下形式的虚拟权重：

y=(Id⊗WId+∑hAh⊗Wh)x+…y = (\text{Id} \otimes W_\text{Id} + \sum_h A^h \otimes W_h) x + …

（一般情况下，hh 可能包括虚拟注意力头。）

我们在本文中看到的主要示例是将 yy 设为输出标记的 logits，将 xx 设为单热编码的输入标记。但这也可能出现在许多其他情况下。例如，yy 可能是 MLP 预激活，而 xx 可能是先前 MLP 层的激活。

乘以 (Id⊗WId+∑hAh⊗Wh)(\text{Id} \otimes W_\text{Id} + \sum_h A^h \otimes W_h) 可以看作是卷积的推广，权重 [WId, Wh0, Wh1... ][W_\text{Id}, ~ W_{h_0}, ~ W_{h_1}...~] 和注意力头代替了相对位置。

E在有限情况下与标准卷积的精确等价：我们声称所有卷积都可以表示为上面的张量乘积之一，因此（1）注意力是卷积的推广； (2) 注意力的具体配置与卷积完全对应。

考虑卷积 W∗xW \ast x。我们声称它可以重写为：

W∗x = ∑vAv⊗WvW \ast x ~=~ \sum_v A^v \otimes W_v

其中vv是卷积偏移量，AvA^v是始终关注相对位置vv（例如前一个令牌头）的注意力模式，WvW_v是与该偏移量对应的权重条目。

Cordonnier et al. [69] 深入探讨了这种等价性，他们还凭经验发现视觉模型通常具有 许多 2D 相对位置头 ，类似于我们之前观察到的令牌头。

与卷积概括的类比: 对于“动态”注意头，与标准卷积的对应关系破裂，“动态”注意头基于除固定相对位置之外的某种模式进行参与。然而，在很多情况下，他们在精神上仍然很像卷积。例如，“前一个动词”头部不是字面上的相对位置（至少如果我们根据标记索引参数化我们的输入），但它在道德上看起来像是一种卷积。

解决上述问题的一种方法可能是考虑图卷积。如果我们将每个注意力模式视为图上的一组不同的权重，则可以将张量积视为图卷积的总和。 （对于 Transformer 和图神经网络之间类比的非正式讨论，读者可能希望查看 Joshi [70] 的文章。）然而，需要考虑多个不同的权重图似乎不太优雅。还有其他基于抽象代数的奇特卷积（参见教程 [71]），也许可以找到正确的版本来找到精确的对应关系。

但最根本的是，当你看到像上面这样的张量积时，它们可以被认为是具有动态、软、可能语义位置的卷积。

为什么有用：在逆向工程卷积神经网络中，Distill Circuits线程[7]从Transformer权重被组织成卷积的事实中受益匪浅。例如，我们可以查看两个神经元之间的权重，看看不同的空间位置如何影响事物。

在上面的例子中，我们看到了两个曲线检测器之间的权重；沿着曲线的切线，另一条曲线会激发它。如果必须查看 25 种不同的权重，这一点就会更难理解；我们从组织中受益。

我们期望类似的组织可能有助于理解Transformer权重，特别是当我们开始考虑 MLP 层时。

激活属性

我们经常发现，根据 Transformer 是否具有以下属性，对 Transformer 中的各种激活进行不同的思考是有帮助的：

Privileged Basis 与 Basis Free：当模型架构的某些方面鼓励神经网络特征与基础维度对齐时，例如由于 ReLU 等稀疏激活函数，就会出现特权基础。在 Transformer 中，唯一具有特权基础的向量是标记、注意力模式和 MLP 激活。请参阅附录变量表，了解哪些激活具有或不具有特权激活的完整列表。

某些类型的可解释性仅对于具有特权基础的激活才有意义。例如，查看激活的“神经元”（即基本维度）（例如残差流、键、查询或值）并没有真正的意义，因为它们没有特权基础。这并不是说没有方法来研究它们；而是说没有方法可以研究它们。在没有假设特权基础的情况下，在词嵌入方面做了很多有趣的工作（e.g. [72]）。但拥有特权基础确实可以开辟有用的方法。

瓶颈激活：如果一个激活是两个高维激活之间的低维中间体，我们就说它是瓶颈激活。例如，残差流是瓶颈激活，因为它是在 MLP 激活之间传递信息的唯一方式，而 MLP 激活通常比它大四倍。 （此外，除了它是相邻 MLP 层之间通信的瓶颈之外，它也是任意早期 MLP 层与任意后期 MLP 层进行通信的唯一途径，因此流可能同时在许多不同对的 MLP 层之间传递不同的信息，这是比 4x 更极端的瓶颈！）类似地，值向量是瓶颈激活，因为它的维度比残差流低得多，并且它是从残差流移动一个标记位置信息的唯一方法在另一个上下文中（模型没有将额外的注意力集中在同一模式上，有时它会这样做）。请参阅上表，了解哪些激活是或不是瓶颈激活的列表。

具有位置嵌入的指针算法

我们的模型使用了一种稍微不寻常的位置机制（类似于 [10]），它不会将位置信息放入残差流中。流行的旋转注意力 [9] 位置方法也具有相同的属性。但值得注意的是，当模型确实具有位置嵌入时（如 [1] 中），就会出现几种可能性。

在最基本的层面上，位置嵌入有点像令牌地址。注意力头可以使用它们来更喜欢关注某些相对位置的标记，但它们还可以做更多的事情：

  • 转换器可以对位置嵌入执行“指针算术”类型的操作。我们在 GPT-2 中观察到至少一种情况，其中使用这种方法而不是上述方法来实现归纳头。首先，注意力头关注类似的标记，返回其位置嵌入。接下来，使用 q-composition 构建另一个注意力头的查询向量，将位置嵌入向前旋转一个标记。这产生了归纳头。
  • 我们推测，在某些情况下，每个令牌都有一个标识符可能会很有用。例如，假设您希望同一句子中的所有标记共享一个标识符。在位置模型中，注意力头可以关注前一时期并将其位置嵌入复制到某个子空间中。

张量积/克罗内克积符号

在机器学习中，我们经常处理要与“一侧”相乘的矩阵和张量。具体来说，在 Transformer 中，我们的激活通常是表示不同上下文索引处的向量的 2D 数组，并且我们通常希望“每个位置”或“跨位置”相乘。通常，我们想两者兼得！张量（或等效的克罗内克）乘积是表示这一点的一种非常简洁的方式。我们用 ⊗\otimes 符号表示它们。

非常务实：

  • 像 Id⊗W\text{Id} \otimes W 这样的乘积（左边有恒等式）表示将我们上下文中的每个位置乘以一个矩阵。
  • 像 A⊗IdA \otimes \text{Id} 这样的乘积（右侧有标识）代表不同位置的乘法。
  • 像 A⊗WA \otimes W 这样的乘积将每个位置的向量乘以 WW，并在各个位置乘以 AA。按照哪个顺序执行此操作并不重要。
  • 产品遵循混合产品属性 (A⊗B)⋅(C⊗D)=(AC)⊗(BD)(A \otimes B) \cdot (C \otimes D) = (AC) \otimes (BD)。

有几种完全等效的方法来解释这些产品。如果该符号不熟悉，您可以选择您觉得最舒服的符号：

  • 左右相乘： 将xx乘以张量积A⊗WA\otimes W相当于同时左右相乘：(A⊗W)x=AxWT(A\otimes W) x = A x W^T。当我们将它们相加时，就相当于将这个乘法的结果相加：(A1⊗W1+A2⊗W2)x(A_1\otimes W_1 + A_2\otimes W_2) x =A1xW1T+A2xW2T= A_1 x W_1^T + A_2 x W_2^T。
  • Kronecker 乘积： 我们要执行的操作是对激活矩阵 xx 的扁平（“向量化”）版本进行线性变换。但是展平给了我们一个巨大的向量，我们需要将矩阵映射到一个更大的块矩阵，该矩阵执行诸如“将先前对应于向量的元素乘以该矩阵”之类的操作。执行此操作的正确操作是 Kronecker 产品。因此，我们可以将 ⊗\otimes 解释为作用于 xx 向量化的克罗内克积，并且一切都是等效的。
  • 张量积： A⊗WA\otimes W 可以解释为 张量积 将矩阵 AA 和 WW 转换为 4D 张量。在 NumPy 表示法中，它相当于 A[:,:,None,None] * W[None, None, :, :]（尽管人们不会在计算上以这种形式表示它们）。更正式地说，AA 和 WW 是“(1,1)(1,1) 类型”张量（将向量映射到向量的矩阵），而 A⊗WA\otimes W 是“(2,2)(2,2) 类型”张量（可以将矩阵映射到矩阵）。

处理层归一化

我们的Transformer模型每次从残差流中读取数据时都会应用层归一化。在实践中，这样做是为了鼓励健康的激活和梯度缩放，使 Transformer 更容易训练。然而，这也意味着每一层的“读”操作比我们上面描述的理想化版本更复杂。在本节中，我们将描述如何解决此问题。

在考虑层标准化之前，我们先考虑一下批量标准化的更简单情况。由于自回归模型中使用批量归一化的微妙之处，Transformer 通常使用层归一化而不是批量归一化，但这是一个很容易解决的情况，并且将使我们的理论与模型完全一致。批量归一化跟踪其输入的均值和方差的移动估计，并使用它来独立地对它们进行归一化，然后使用学习的参数进行重新缩放。在推理时，使用均值和方差的固定估计。这意味着它只是一个固定的线性变换和偏差，可以乘以相邻学习的线性变换和偏差。因此，模型中的批量归一化通常可以被吸收到其他操作中，并为了推理时间模型的可解释性而被忽略。

层归一化有点微妙。对于每个残差流向量，我们减去平均激活值，通过方差进行归一化，然后乘以一组学习到的对角权重并添加学习到的偏差向量。事实证明，减去平均激活是一个固定的线性变换，因为它只是将向量空间中的单个维度归零。这意味着除了方差归一化之外，层归一化都应用固定的仿射变换。按方差标准化将向量乘以标量，而乘以标量则与路径中的所有其他操作进行交换。因此，我们可以将除归一化之外的所有内容折叠到相邻参数中，然后将归一化缩放视为经过该层归一化的路径项集的变量重新加权。 （这样做的主要缺点是，这意味着穿过不同层集的路径不容易进行比较；例如，我们无法简单地比较由不同层的头组成的虚拟注意力头的重要性。）

最后的观察结果是，模型的第一个注意力层中的层归一化可以选择性地应用于嵌入矩阵的每个向量，然后被忽略。在某些情况下，这更方便（例如，我们对单层模型中的跳跃三元语法执行此操作）。

未来，尽管它很复杂，但可能值得尝试使用批量归一化来训练模型，以避免成为一个痛点。

使用低阶矩阵

在本文中，我们发现自己正在处理非常大但秩极低的矩阵。选择正确的算法通常是 GPU 上极其缓慢的操作与 CPU 上一切瞬间完成之间的区别。

首先，我们建议尽可能将矩阵保持为因子形式。当矩阵链相乘时，确定“最小”瓶颈点并将矩阵表示为在该瓶颈处分割的乘积 ABAB。

Eigenvalues: 利用 λi(AB)=λi(BA)\lambda_i(AB) = \lambda_i(BA) [75] 的事实。计算 64×64 矩阵的特征值比 50,000×50,000 矩阵的特征值要好得多。

SVD: SVD 也可以有效地计算，并且可以使用变体来有效地计算 PCA：

  • 计算 AA 和 BB 的 SVD：UASAVA=AU_AS_AV_A = A 和 UBSBVB=BU_BS_BV_B = B。
  • 定义C=SAVAUBSBC=S_AV_AU_BS_B
  • SVD CC：UCSCVC=CU_CS_CV_C = C
  • ABAB 的 SVD 为 UAB=UAUCU_{AB} = U_AU_C、SAB=SCS_{AB} = S_C、VAB=VCVBV_{AB} = V_CV_B。
